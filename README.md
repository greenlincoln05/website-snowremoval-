# North Country Snow Removal website

Website, QR assets, and flyer design sources for a residential snow removal business in Plattsburgh, NY.

- `index.html` is the live one-page site (static, mobile-first, SEO-ready).
- `assets/` holds the QR code for the monthly sign-up link.
- `design/` holds the flyer and storefront design sources.
- **`HANDOFF.md` has the full context and the ordered next steps** (embedded Stripe checkout, Supabase database, Cloudflare hosting).

Open `index.html` in a browser to preview. Nothing here needs a build step yet.
